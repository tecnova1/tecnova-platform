# TECNOVA SpA — Plataforma Digital (Next.js MVP)

SaaS modular y escalable para el Centro de Investigación y Observatorio de Fricción Organizacional (IFO / IFC).

## 🚀 Despliegue en Vercel

1. Sube este proyecto a un repositorio en **GitHub**.
2. Conecta tu cuenta de GitHub a **Vercel.com**.
3. Selecciona el repositorio e importa el proyecto.
4. Vercel detectará automáticamente **Next.js** y construirá el sitio en segundos.

## 🛠️ Desarrollo Local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
