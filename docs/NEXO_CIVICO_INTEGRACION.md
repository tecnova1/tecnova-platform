# Nexo Cívico en TECNOVA

TECNOVA no presenta Nexo Cívico como un producto de software. Lo presenta como un **instrumento de investigación territorial** que permite observar una experiencia, registrar evidencia y comprender antes de intervenir.

## Puerta institucional

- Inicio: `/nexo`
- Nosotros: módulo Nexo Cívico
- Navegación principal: Nexo Cívico

## Destino operativo

La página `/nexo` funciona como gateway hacia el despliegue operativo de Nexo.

Configurar en el entorno de producción:

`NEXT_PUBLIC_NEXO_CIVICO_URL=<URL_PUBLICA_DE_NEXO>`

No se fija una URL inventada en el repositorio.

## Lenguaje

TECNOVA: **investigar antes de innovar**.

Nexo Cívico: **observar → registrar → comprender → movilizar → medir**.

El software es el instrumento; el objeto es la experiencia humana y el conocimiento que se obtiene de ella.
